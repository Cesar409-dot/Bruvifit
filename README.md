# Bruvifit

## 📌 Sobre o Projeto

O **Bruvifit** é um projeto acadêmico de Pesquisa e Inovação desenvolvido por estudantes da **São Paulo Tech School (SPTech)**.

A proposta é desenvolver uma solução tecnológica para auxiliar na **centralização e organização das informações** de uma microempresa do segmento de moda fitness.

O sistema busca reunir informações de diferentes áreas do negócio em um único ambiente, facilitando o acompanhamento das operações e a tomada de decisões.

---

## 🎯 Objetivo

Desenvolver um sistema centralizado de gestão da informação, contemplando principalmente:

* 💰 Gestão financeira;
* 📦 Controle de estoque;
* 🛍️ Gestão de vendas e pedidos;
* 👥 Gerenciamento de clientes;
* 📊 Visualização e análise de dados;
* 🏷️ Apoio à precificação dos produtos.

---

## 💡 Solução Proposta

A solução consiste em um sistema de gestão que centraliza informações importantes da Bruvifit.

Entre as funcionalidades previstas estão:

* Cadastro, consulta e atualização de produtos;
* Controle de estoque;
* Gerenciamento de pedidos;
* Consulta de informações de clientes;
* Análise de dados financeiros;
* Dashboards para acompanhamento das informações;
* Identificação de produtos de maior desempenho;
* Alertas relacionados ao estoque;
* Consulta de endereço por CEP.

## 📋 Metodologia

O projeto é desenvolvido de forma incremental, utilizando **sprints** para organizar as atividades da equipe.

O planejamento contempla cinco sprints:

| Sprint       | Atividade                                         |
| ------------ | ------------------------------------------------- |
| **Sprint 1** | Diagnóstico, mapeamento de requisitos e processos |
| **Sprint 2** | Estruturação do projeto e requisitos essenciais   |
| **Sprint 3** | Desenvolvimento e integração do MVP               |
| **Sprint 4** | Implantação, testes e validação                   |
| **Sprint 5** | Refinamento, polimento e entrega final            |
