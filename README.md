## Branches

### `develop`

Branch utilizada para o desenvolvimento, testes e integração das funcionalidades do projeto.

Após as funcionalidades serem desenvolvidas e validadas na `develop`, as alterações são integradas e **sobem para a `main`**, que mantém a versão estável do projeto.

### Fluxo

`develop` → desenvolvimento e testes → `main` → versão estável
